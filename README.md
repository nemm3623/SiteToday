# 오늘현장 (SiteToday)

오늘현장은 일용직 근로자가 집에서 원하는 현장에 지원하고, **출발 전에 배정 결과와 집결 장소·시각을 확인**할 수 있도록 기획한 스프링 백엔드 프로젝트입니다.

사무소와 집이 멀어 새벽부터 나갔다가 일감이 없어 돌아왔던 경험에서 시작했습니다. 전화하면 그날 일감이 있는지는 알 수 있었지만, 근로자가 출발을 결정하는 데 필요한 정보는 **어느 현장에 내 자리가 확정됐는지**입니다.

**개발 단계** · 현재 저장소에는 Spring Boot 기본 애플리케이션과 컨텍스트 로딩 테스트가 있습니다. 아래 서비스 흐름은 2주 동안 구현할 첫 버전의 목표입니다.

## 첫 버전의 이용 흐름

1. **고용주가 사무소를 선택합니다.** 근무 날짜와 시간, 작업 내용, 인원, 일당을 담아 인력을 요청합니다.
2. **사무소가 공고를 게시합니다.** 배정 마감 시각과 현장 주소를 안내합니다. 픽업을 제공하는 공고에는 사무소 주소와 집결 시각도 표시합니다.
3. **근로자가 원하는 현장에 지원합니다.** 날짜별 공고를 살펴보고 현장 직행 또는 사무소 픽업을 선택합니다. 시간이 겹치는 공고에도 지원할 수 있습니다.
4. **사무소가 배정을 확정합니다.** 담당자가 지원자의 근무 이력과 리뷰를 참고해 선택하면 근로자는 즉시 앱에서 확정 알림을 받습니다. 시간이 겹치는 다른 지원은 자동 취소되고, 다른 시간대의 지원은 유지됩니다.
5. **고용주가 출석과 리뷰를 기록합니다.** 배정 명단과 이전 리뷰를 확인하고, 아침에 현장에서 출석을 체크합니다. 근무 후에는 출석한 근로자의 해당 근무에 별점과 한 줄 후기를 남깁니다. 근로자는 후기를 확인하고 답글을 달 수 있습니다.

## 데이터베이스로 검증할 배정 규칙

| 동시에 일어나는 상황 | 요청 처리 후 확인할 결과 |
| --- | --- |
| 두 사무소가 같은 근로자를 시간이 겹치는 현장에 각각 배정 | 확정된 배정은 한 건이며 다른 날짜의 지원은 유지됩니다. |
| 두 담당자가 한 현장의 마지막 한 자리에 서로 다른 근로자를 배정 | 한 명만 확정됩니다. 배정에 실패한 근로자의 다른 현장 지원은 유효합니다. |

## 후속 기능

- **요청 조건 변경** · 사무소가 변경을 제안하고 고용주가 수락하면 합의된 조건으로 게시합니다.
- **결원 대기** · 정원이 차거나 배정 마감 시각이 되면 미확정 지원자가 대기를 선택할 수 있습니다. 취소로 자리가 생기면 사무소가 여러 대기자에게 동시에 제안하고 먼저 수락한 사람부터 배정합니다.
- **긴급 모집** · 아침 출석 확인 후 고용주가 대체 인원을 요청하면 사무소가 긴급 공고를 엽니다. 근로자는 지금 합류할 장소와 시각을 보고 지원하고, 담당자가 배정을 확정합니다.

## 로컬 실행

JDK 21을 준비한 뒤 저장소 루트에서 Gradle Wrapper로 실행합니다. 현재 구성은 Spring Boot 4.2.0과 Gradle 9.9.2를 사용합니다.

```sh
./gradlew bootRun
```

기본 애플리케이션 컨텍스트가 로드되는지 확인하는 테스트는 다음 명령으로 실행합니다.

```sh
./gradlew test
```
